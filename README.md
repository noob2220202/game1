# 하루를 위한 방탈출!

새벽 3시 33분. 처음 보는 방. 손에 쥔 건 내 것이 아닌 휴대폰.

친구 **하루**를 위해 만든 모바일 웹 공포 방탈출 게임입니다. 플레이 시간은 약 40분이에요.
'잃어버린 폰 들여다보기' 장르로, 맵은 단 하나입니다. 실종된 전 세입자의 폰과, 그 폰 카메라로 비춰 보는 갇힌 방이에요.

- 📱 진짜 폰 같은 UI: 앱 13개, 게임 내 두벌식 키보드, 알림 배너, 빠른 설정
- 🔊 소리는 전부 Web Audio로 직접 합성: 3D 입체음향(이어폰 권장), 오르골 테마
- 🖼 사진은 AI로 생성한 뒤 직접 합성·편집했고, 목소리는 AI 음성입니다
- 💾 진행 상황은 자동 저장됩니다. 서버로 보내는 데이터는 없어요

## 개인화 (`js/config.js`)
```js
PLAYER_NAME: '하루',        // 게임 속 이름 (조사 자동 처리)
MAKER_NAME: '너의 친구',     // 엔딩 크레딧
ENDING_LETTER: '...',       // 엔딩 편지
```

## 실행
정적 사이트라서 빌드 과정 없이 폴더를 그대로 서비스하면 됩니다.
로컬에서 확인하려면 `python3 -m http.server 8080` 을 실행한 뒤 http://localhost:8080 으로 접속하세요.
`file://` 로 열면 AI 음성 파일이 로드되지 않습니다.

배포(VPS + Caddy): [`deploy/README.md`](deploy/README.md)

## 구조
- `docs/DESIGN.md`: 최종 기획서 (스토리, 퍼즐, 대사, 사운드, 에셋)
- `docs/ARCH.md`: 코드 구조와 모듈 API
- `js/core/`: 엔진 (폰 셸, 오디오, 3D 사운드, 이펙트, 키보드, 위젯)
- `js/apps/`: 폰 앱들
- `js/data/`: 스토리 데이터
- `js/room/`: 방 카메라 뷰, 도어락, 클라이맥스
- `js/director.js`: 공포 연출 디렉터
- `js/scenes.js`: 오프닝과 엔딩
- `tools/`: 에셋 생성·합성 스크립트 (`get_fonts.sh`, `OPENAI_API_KEY` 환경변수 사용)
- `docs/HANDOFF.md`: 2편·시리즈 작업을 PC에서 이어가는 방법

> ⚠️ 정답과 스포일러가 `docs/DESIGN.md` 에 있어요. 플레이할 사람에게는 보여주지 마세요.
