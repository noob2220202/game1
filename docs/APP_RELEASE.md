# 앱 출시 체크리스트

## 규칙 (의뢰인)

> "동그라미 친 저런거 추후에 어플 출시할때는 깔끔하게 없어야해. 알았지?"

2편 엔딩 크레딧에서 동그라미 친 작은 글씨 네 줄(만든 사람 · AI 목소리/사진/소리 · 플레이 n분·힌트 n회 · 데이터 문구)과 화면 아래 초록 디버그 표시(`his 20/25 · tone … · tts …`)를 두고 한 말.
→ 앱(스토어) 빌드에서는 **빈 자리 없이 깔끔하게** 빠져야 한다. 글자만 숨기는 게 아니라 노드 자체가 없고, 제목은 화면 정중앙.
→ **웹은 지금 그대로.**

## 스위치: `js/config.js`의 `APP`

| 값 | 뜻 |
|---|---|
| `APP: false` (기본) | 웹. 지금과 똑같다. |
| `APP: true` | 앱 빌드. 아래가 모두 적용된다. |

`APP: true`일 때 (2편 기준, `ep2/js/config.ep2.js`가 `G.APP`으로 만든다):

- **엔딩 크레딧**: 제목 블록(`{N를} 위한 방탈출! 2` / `돌려줄게`)만 만든다. 만든 사람 · 목소리/사진/소리 · 플레이/힌트 · 데이터 문구는 노드를 아예 만들지 않는다. 제목은 장면 정중앙(`.fl2-credits.app`). 대기 시간 · 음악 · 탭해서 넘기기 · 확인 카드는 웹과 같다.
- **디버그 완전 차단**: `CONFIG.DEBUG`와 `?debug=1`을 무시하고 `G.DEBUG = false`. `window.haru`(치트), 시리즈 `_fixture`, `skipTo`, `?jump=`, `?series=`가 없다. `G.ending.debugM8`, `G.clock._scale`, `G.audio.meter`, `G.fx.roomLook`, `G.e2.budget`도 정의하지 않는다.
- **화면 디버그 표시 없음**: 초록 계측기, 빨간 오류 줄, 핫스팟 점선 테두리(`.rm2-debug`), `body.debug`.

1편은 `APP` 키를 읽지 않는다(1편 코드는 정해진 키만 이름으로 읽고, `CONFIG` 키를 순회하는 곳이 없다). 그래서 이 키를 넣어도 1편 출시본은 그대로다.

## AI 음성 고지 — 출시 전에 결정할 것

- 앱에서는 크레딧의 `목소리: AI 음성` 줄이 빠진다. 그런데 **OpenAI TTS 이용 정책은 최종 사용자에게 그 목소리가 AI로 만든 것임을 명확히 알리도록 요구한다.** 출시 전에 의뢰인이 고지 위치를 정한다: 스토어 설명 또는 앱 안 '앱 정보' 화면.
- 한국 **AI 기본법**(인공지능 발전과 신뢰 기반 조성 등에 관한 기본법)의 투명성 의무(생성형 AI 사용 고지, 생성물 표시 등)도 출시 시점 기준으로 확인한다.

## 미리보기

- `ep2/index.html?app=1` — 운영 호스트(`*.pengueverything.cloud`) **밖에서만** 켜진다(로컬 `file://`, 스테이징). 앱과 같은 화면.
- `ep2/index.html?app=1&debug=1` — 같은 화면에 QA용 점프(`haru.jump` 등)만 살아 있다. 화면 디버그 표시는 그래도 안 보인다.
- 운영 호스트에서는 `?app=1`을 무시한다(웹 그대로).

## 확인

```
NODE_PATH=<전역 node_modules> node tools/qa/app_mode.js [--ep=2] [--baseline=<원본 체크아웃>]
```

- **a 웹** `?debug=1`: 크레딧 다섯 노드와 문구가 그대로, 디버그 표시가 보인다(검사가 제대로 보는지 확인). `--baseline`을 주면 크레딧 HTML을 원본 체크아웃과 비교.
- **b 앱 미리보기** `?app=1&debug=1`: 제목만, 네 문구가 `document.body.innerText` 어디에도 없음, 디버그 표시 없음, 360×740 · 390×844 · 430×932 × 글자 크기 1 · 1.3에서 정중앙(±4 px).
- **c 실제 앱 빌드**(`js/config.js`를 `APP: true`로 바꿔 서빙): `G.DEBUG` false, 디버그 도우미 없음, 타이틀 → 경고 → 이어폰 테스트 → 오프닝 → 첫 시점 화면, `CONFIG.DEBUG: true`여도 false, 저장 이어하기 → 크레딧 = 제목만.
- 모든 실행에서 콘솔 오류 0. 스크린샷은 `work/qa/appmode/`. 통과 = 종료 코드 0.
- 회귀: `ep2_speedrun.js`, `ep2_speedrun.js --ep1=done`, `ep2_branches.js`.
